# 문답 건너뛰기 변경 안내 (앱 전달용)

건너뛰면 다른 질문으로 교체해서 5개를 채우는 방식으로 바꿉니다.

## 1. 규칙

- 필수 질문(앞 2개): 건너뛰기 불가. 버튼을 노출하지 않습니다.
- 선택 질문(뒤 3개): 건너뛰면 여분 질문으로 교체합니다.
- 여분이 다 떨어진 뒤 건너뛰면 그 문항은 빼고 진행합니다(기존 동작).

## 2. `GET /diaries/question` 응답에 `optionalSpares` 필드가 추가됩니다

```json
{
  "questions": ["필수1", "필수2", "선택1", "선택2", "선택3"],
  "optionalSpares": ["선택 여분1", "선택 여분2"]
}
```

- `questions`: 기존과 동일. 항상 5개이고 0~1번이 필수, 2~4번이 선택입니다.
- `optionalSpares`: 선택 질문 여분. 0~5개이고 `questions` 와 겹치지 않습니다. 없으면 빈 배열입니다(null 아님).

## 3. 앱 처리

- 선택 질문을 건너뛰면 `optionalSpares` 앞에서부터 하나 꺼내 그 자리에 넣습니다.
- 질문 조회는 작성 화면 진입 때 한 번만 호출하고, 건너뛸 때 다시 부르지 않습니다. 호출마다 새로 무작위로 뽑혀서 중복이 생깁니다.
- 서버 DB 사정에 따라 여분이 5개보다 적게 올 수 있으니 개수를 가정하지 마세요.

## 4. `POST /diaries/qna` 는 변경 없습니다

- 답한 문항만 보냅니다. `question` 에는 화면에 실제로 보여준(교체된) 질문 문구를 넣습니다.

기존 필드는 그대로라 지금 앱은 깨지지 않습니다.
